# Desktop Pet

바탕화면 위에 이미지가 떠 있는 데스크톱 앱 (Electron).
단계별 계획과 검토한 기술 이슈는 [docs/plan.md](docs/plan.md) 참고.
다른 PC에서 이어서 작업할 때는 [docs/handoff.md](docs/handoff.md) 참고.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

## 설치

[최신 설치 프로그램 내려받기](https://github.com/m3rri/desktop-pet/releases/latest/download/DesktopPet-Setup.exe) (`DesktopPet-Setup.exe`)를 실행합니다. 지난 버전은 [Releases](https://github.com/m3rri/desktop-pet/releases)에 있습니다.

- 기본은 "현재 사용자만" 설치라 관리자 권한이 필요 없습니다 (`%LOCALAPPDATA%\Programs\Desktop Pet`)
- 시작 메뉴와 바탕화면에 바로가기가 생기고, 설정 → 앱에서 제거할 수 있습니다
- 제거해도 설정·로그 폴더(`%APPDATA%\desktop-pet`)는 남습니다. 다시 설치하면 그대로 이어서 씁니다
- 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜨면 "추가 정보 → 실행"

## 빌드

```bash
npm install
npm run dist:win      # 설치 프로그램 → dist/installer/DesktopPet-Setup.exe (내 PC에만 만들고 올리지 않음)
npm run package:win   # 압축 버전(설치 없이 실행) → dist/desktop-pet-win32-x64/
```

`dist:win`은 Windows에서 실행하면 바로 됩니다. Linux·macOS에서는 Wine(32비트 포함)이 필요합니다.
electron-builder가 제거 프로그램을 만들 때 설치 프로그램을 한 번 실행하기 때문입니다.

## 배포

`v<버전>` 태그를 push하면 GitHub Actions(`.github/workflows/release.yml`)가 Windows에서 설치 프로그램을 빌드해 [Releases](https://github.com/m3rri/desktop-pet/releases)에 올립니다.

1. `package.json`의 `version`을 올려 커밋 (예: `1.4.2`)
2. `git push origin main`
3. `git tag v1.4.2` → `git push origin v1.4.2`
4. Actions 탭에서 끝나면 Release에 `DesktopPet-Setup.exe`, `latest.yml`, `.blockmap`이 올라감

- 태그와 `package.json` 버전이 다르면 빌드하지 않고 멈춥니다
- Release는 초안으로 먼저 만들고, 파일이 다 올라간 뒤에 공개합니다 (같은 태그의 Release가 2개 생기거나, 파일이 덜 올라간 Release를 latest 링크가 가리키는 것을 막기 위해)
- 설치 파일 이름에 버전을 넣지 않아서 `releases/latest/download/DesktopPet-Setup.exe`가 항상 최신 버전을 가리킵니다
- `latest.yml`은 나중에 앱 안 자동 업데이트(electron-updater)가 최신 버전을 확인할 때 씁니다
- 업로드 권한은 Actions에 기본으로 주어지는 `GITHUB_TOKEN`을 씁니다. 다만 `.github/workflows` 파일을 push하려면 push에 쓰는 토큰(fine-grained PAT)에 **Workflows: Read and write** 권한이 있어야 합니다

앱 아이콘(`assets/icon.ico`)은 `npm run make-pets`가 곰을 크기별(16~256px)로 다시 그려서 만듭니다.

## 조작

| 동작 | 방법 |
|---|---|
| 이동 | 이미지를 드래그 |
| 반응 | 이미지를 클릭 (캐릭터마다 여러 동작 중 하나) |
| 밥 주기 | 밥그릇을 더블클릭 → 캐릭터가 걸어와서 먹음. 빈 그릇은 더블클릭해서 다시 채움. 밥그릇은 드래그로 옮김 |
| 메뉴 | 캐릭터 또는 밥그릇을 우클릭 (밥그릇 메뉴에는 "밥 먹으러 오게 하기"·"밥그릇 채우기"가 맨 위에 더 있음) |
| 말 걸기 | 이미지를 더블클릭 → 머리 위 말풍선에 대사. 3번에 1번은 퇴근(또는 마감)까지 남은 시간 |
| 숨기기/보이기 | `Ctrl + Alt + P`(설정에서 변경 가능), 트레이 아이콘 클릭, 또는 이미지 우클릭 메뉴 |
| 설정 | 이미지 우클릭 → 설정…, 또는 트레이 아이콘 더블클릭 |
| 캐릭터 바꾸기 | 설정 화면, 또는 이미지 우클릭 → 캐릭터 |
| 표시할 모니터 | 설정 화면, 또는 이미지 우클릭 → 표시할 모니터 |
| 전체 화면 앱 중 숨기기 | 설정 화면, 또는 이미지 우클릭 (기본 켜짐) |
| 자동 실행 | 설정 화면, 또는 이미지 우클릭 (빌드한 exe에서만) |

이미지의 투명한 부분은 클릭이 뒤에 있는 창으로 통과합니다. 캐릭터가 그려진 부분만 클릭·드래그됩니다.
| 종료 | 이미지 우클릭 → 종료, 또는 트레이 아이콘 우클릭 → 종료 |

트레이는 작업표시줄 오른쪽 끝(시계 옆) 아이콘 영역입니다. 안 보이면 `^`를 누르세요.

이미 실행 중일 때 exe를 다시 실행하면 새로 뜨지 않고 기존 창을 다시 보여줍니다.

## 캐릭터 동작

| 상태 | 언제 | 재생 |
|---|---|---|
| idle | 기본 | 반복 |
| walk | 2~6초 쉬다가 현재 모니터 안의 근처 지점으로 이동 | 반복 |
| click | 클릭했을 때 | 1회 재생 후 idle. 이미지가 여러 개면 무작위 |
| eat | 밥그릇에서 먹는 동안 (선택). 없으면 idle | 반복 |
| dblclick | 더블클릭했을 때 (선택). 이미지가 없으면 멈춰 서서 말풍선만 띄움 | 1회 재생 후 idle |
| drag | 드래그하는 동안 | 반복 |
| sleep | 키보드·마우스 입력이 `sleepAfterSec`초 동안 없을 때. 입력이 생기면 깨어남 | 반복 |

### 더블클릭과 말풍선

- 클릭과 더블클릭을 구분하려고, 클릭하면 0.25초 동안 두 번째 클릭을 기다린 뒤 클릭 동작을 재생합니다. 그래서 클릭 반응이 그만큼 늦지만, 더블클릭할 때 클릭 동작이 먼저 시작되지 않습니다
- 더블클릭하면 걷거나 자던 캐릭터가 멈추고, 머리 위 말풍선에 `pet.json`의 `phrases` 중 하나를 무작위로 보여줍니다(직전과 같은 대사는 연달아 나오지 않음). `phrases`가 없으면 앱 기본 대사를 씁니다
- 말풍선은 2.5~6초(글자 수에 따라) 뒤에 사라지고, 캐릭터를 끌면 따라다닙니다. 화면 가장자리에서는 안쪽으로 밀리고 꼬리가 캐릭터를 가리킵니다
- 말풍선 글자는 이미지가 아니라 글자로 그립니다(이후 퇴근 시간 알림처럼 매번 바뀌는 문구에 쓰기 위해)
- 폰트는 앱에 같이 넣은 [Gaegu](assets/fonts/gaegu/OFL.txt)(SIL Open Font License 1.1)를 씁니다. 사용자 PC에 설치된 폰트와 상관없이 같은 모양으로 보이고, 불러오지 못하면 맑은 고딕으로 대신 표시합니다

## 설정 화면

바꾸면 바로 적용되고 저장됩니다 (저장 버튼 없음). 메뉴에서 바꾼 값도 설정 화면에 바로 반영됩니다.

| 항목 | 내용 |
|---|---|
| 캐릭터 | 기본 제공(곰, 검은 고양이, 푸들, 토끼, 쿼카, 오목눈이)과 내 폴더 중에서 선택. **새 캐릭터 폴더**로 빈 폴더(`%APPDATA%\desktop-pet\pets\새 캐릭터`)를 만들어 이미지를 넣을 수 있음. 이미지를 넣기 전에는 "이미지를 넣어 주세요"로 표시되고, 넣은 뒤 설정 창으로 돌아오면 바로 고를 수 있음. 재시작 없이 바로 바뀜. **폴더 추가**로 다른 폴더를 등록할 수 있고, 폴더 안 이미지를 바꿨으면 **다시 불러오기** |
| 크기 | 64~256px. 발 위치를 고정한 채 커지고 작아짐 |
| 이동 속도 | 0~200px/초. 0이면 제자리 |
| 잠들기까지 | 캐릭터 기본값 / 안 잠 / 1~60분 |
| 표시할 모니터, 전체 화면 숨기기, 자동 실행 | 메뉴와 같음 |
| 남은 시간 알림 | 퇴근 시간(매일 시각) / 마감 날짜 / 사용 안 함 중 선택. 아래 "남은 시간 알림" 참고 |
| 숨기기/보이기 단축키 | 버튼을 누르고 원하는 조합 입력. Ctrl·Alt·Win 중 하나가 있어야 함(F 키는 단독 가능). 다른 프로그램이 쓰는 조합이면 원래 단축키 유지 |

크기·속도·잠들기를 "기본값으로" 되돌리면 캐릭터 `pet.json`의 값을 씁니다.

### 밥그릇

화면 한쪽(처음에는 오른쪽 아래)에 밥그릇이 놓여 있습니다. 드래그로 옮기면 그 자리를 기억합니다.

- 밥그릇을 더블클릭하면 캐릭터가 하던 일을 멈추고 평소보다 5% 빠르게 걸어와서, 그릇 뒤에 서서 5초 동안 먹습니다. 먹는 동안 음식이 반쯤 → 빈 그릇으로 줄고, 다 먹으면 "냠냠 잘 먹었다! 😋" 같은 말을 합니다
- 빈 그릇을 더블클릭하면 다시 채워집니다
- 음식은 캐릭터마다 다릅니다: 곰 연어(한입 베어 문 자리에 주황색 살), 고양이 생선, 푸들 사료, 토끼 당근, 쿼카 나뭇잎, 오목눈이 씨앗
- 가는 중에 그릇을 옮기면 따라가고, 캐릭터를 끌거나 클릭하면 그만둡니다. 이동 속도가 0(제자리)이어도 밥은 먹으러 옵니다
- 표시할 모니터를 고정해 두었으면 다른 모니터에 있는 그릇까지는 가지 않고 "밥그릇이 너무 멀어 😢"라고 말합니다
- 설정 화면 "밥그릇" 또는 우클릭 메뉴 "밥그릇 보이기"에서 숨길 수 있습니다
- 밥그릇을 우클릭해도 캐릭터 우클릭과 같은 메뉴가 나옵니다. 캐릭터가 돌아다녀서 우클릭하기 어려울 때 쓰면 됩니다
- 직접 만든 캐릭터는 `eat.png`(먹는 동작, 반복)와 `bowl_full.png`·`bowl_half.png`·`bowl_empty.png`(112x72, 캐릭터 128px 기준)를 넣으면 씁니다. 그릇 이미지가 없으면 기본 사료 그릇, `eat` 이미지가 없으면 idle 이미지로 먹습니다

### 남은 시간 알림

더블클릭 3번 중 1번(3번째, 6번째…)은 대사 대신 남은 시간을 말합니다. 설정 화면에서 기준을 고릅니다.

| 기준 | 남은 시간 | 말풍선 |
|---|---|---|
| 퇴근 시간 (매일 같은 시각, 기본 18:00) | 5시간 이상 | 캐릭터 공통으로 정색: "퇴근은 꿈도 꾸지마", "일 안 해?", "아직 한참 남았어. 일해" 중 무작위 |
| | 5시간 미만 | `퇴근까지 4시간 59분 59초 😐` → 4시간 이하 🙂 → 3시간 이하 😊 → 2시간 이하 😆 → 1시간 이하 🤩 → 30분 이하 🥳 |
| | 지났음 | "퇴근 시간이야! 얼른 집에 가 🏃" 등 |
| 마감 날짜 (직장인이 아닌 경우. 종류와 날짜·시각을 고름) | 2주 이상 | 여유: "시험? 아직 한참 남았지~ 🌿" 등 무작위 |
| | 1주 이상 | 이제 슬슬 + 남은 일수: "이제 슬슬 공부해야지? 시험까지 9일 남았어 📝" 등 |
| | 1주 미만 | 남은 일수 + 시간: `과제 마감까지 3일 2시간 남았어 😯` |
| | 하루 전 | 남은 시간: `원고 마감까지 26시간 남았어 😰` |
| | 당일 | 시간 + 분 + 초: `오늘 시험! 2시간 29분 45초 남았어 🔥` |
| | 지났음 | "시험 끝! 수고했어 🎉" / "과제 마감 지났어…! 😱" 등 |

- 마감 종류: 시험(기본), 과제, 원고, 프로젝트, 기타. 종류에 따라 문구가 바뀝니다 (기타는 "마감까지 …")
- 남은 날은 오늘과 마감일의 달력 날짜 차이로 셉니다. 남은 일수·시간은 마감 시각까지 실제로 남은 시간입니다
- 마감 시각을 비워 두면 그날 밤 12시가 마감입니다

- 남은 시간 말풍선은 떠 있는 동안 1초마다 초가 줄어듭니다
- **때가 되면 먼저 알려주기**(기본 켜짐): 더블클릭하지 않아도 퇴근 1시간·30분·10분 전과 퇴근 시각(마감은 하루·1시간·10분 전과 마감 시각)에 캐릭터가 클릭 동작을 하며 8초 동안 말합니다. 캐릭터를 숨겼거나 끄는 중이면 건너뛰고, 절전 등으로 5분 넘게 늦었으면 알리지 않습니다
- 시각은 내 PC 시간 기준입니다
- "사용 안 함"이거나 마감 날짜를 비워 두면 항상 평소 대사를 말합니다
- 이모지는 Gaegu 폰트에 없어서 Windows 이모지 글꼴(Segoe UI Emoji)로 표시됩니다

### 정지 이미지 선 일렁임

정지 이미지(PNG 한 장 등)를 불러오면 앱이 픽셀을 아주 조금씩 다르게 휘게 한 3장을 만들어 번갈아 보여줍니다(220ms 간격). 직접 넣은 그림 한 장도 기본 캐릭터처럼 외곽선이 손그림 애니메이션처럼 일렁입니다. 설정의 "정지 이미지 선 일렁임"으로 끌 수 있고, 움직이는 이미지(GIF, APNG 등)에는 적용하지 않습니다.
**새 캐릭터 폴더 만들기**는 `%APPDATA%\desktop-pet\pets\새 캐릭터` 폴더를 만들어 열고 목록에 추가합니다. idle 이미지를 넣기 전까지는 "이미지를 넣어 주세요"로 표시되고, 이미지를 넣고 설정 창으로 돌아오면 바로 고를 수 있습니다.
트레이 아이콘은 지금 캐릭터의 대표 이미지로 바뀝니다.

## 여러 모니터

이미지 우클릭 → **표시할 모니터**에서 고릅니다.

| 선택 | 동작 |
|---|---|
| 자동 (기본값) | 지금 있는 모니터 안에서만 돌아다님. 드래그로 다른 모니터에 옮기면 거기서 돌아다님 |
| 특정 모니터 | 그 모니터 안에서만 돌아다님. 다른 모니터로 드래그해 놓으면 설정이 그 모니터로 바뀜 |

- 설정한 모니터를 빼면 주 모니터로 옮겨 가고, 다시 연결하면 원래 모니터로 돌아옵니다. 메뉴에는 "연결 안 됨 - 주 모니터에 표시 중"으로 나옵니다.
- 모니터는 순서나 ID가 아니라 이름·위치·크기로 기억합니다. 케이블을 다시 꽂거나 도킹을 바꿔 ID가 달라져도 같은 모니터를 찾습니다.
- 해상도·배율이 바뀌거나 작업표시줄 위치가 바뀌면 화면 밖으로 나가지 않게 위치를 다시 맞춥니다.

## 전체 화면 앱

게임, 영상 플레이어, 브라우저 F11처럼 모니터 전체를 덮는 앱이 맨 앞에 오면 캐릭터를 숨깁니다.

- 캐릭터가 있는 모니터만 확인합니다. 다른 모니터에서 영상을 전체 화면으로 봐도 캐릭터는 그대로 있습니다.
- 최대화한 창은 전체 화면으로 보지 않습니다. 창 크기가 모니터와 정확히 같을 때만 전체 화면으로 판단합니다.
- 숨겨진 동안 `Ctrl + Alt + P`로 다시 보이게 하면, 그 전체 화면이 끝날 때까지는 자동으로 숨기지 않습니다.
- Electron에 이 기능이 없어 `koffi`로 Windows API(user32.dll)를 직접 호출합니다 (`src/fullscreen.js`).

## 캐릭터 바꾸기

아래처럼 이미지를 넣은 폴더를 만들고 설정 화면의 **폴더 추가**로 고르면 됩니다.
`%APPDATA%\desktop-pet\pet` 폴더는 따로 추가하지 않아도 목록에 나옵니다. 설정에서 캐릭터를 고른 적이 없으면 이 폴더가 우선입니다.

```
%APPDATA%\desktop-pet\pet\
├── idle.png      필수. 이미지가 없는 상태는 이 이미지로 대체
├── walk.gif
├── click_1.gif   ┐
├── click_2.gif   │ 같은 상태에 여러 개를 두면
├── click_3.webp  │ 그 상태가 될 때마다 하나를 무작위로 재생
├── click_4.gif   │ (직전과 같은 이미지는 연달아 나오지 않음)
├── click_5.gif   ┘
├── sleep.png
├── drag.png
└── pet.json      선택
```

- 파일 이름 = `상태이름.확장자` 또는 `상태이름_아무거나.확장자` (예: `click.gif`, `click_2.gif`, `click_jump.webp`). 확장자는 `.png`, `.apng`, `.gif`, `.webp` 중 아무거나
- 어느 상태든 여러 개 둘 수 있음. 반복 상태(walk, idle 등)는 그 상태에 들어갈 때 하나를 골라 끝날 때까지 유지
- 읽지 못한 파일은 건너뛰고 나머지로 동작
- 정지 이미지와 애니메이션(GIF, APNG, 애니메이션 WebP) 모두 가능. 투명 배경 권장
- 이미지는 오른쪽을 바라보게 그리면 왼쪽으로 걸을 때 자동으로 뒤집힘 (`facing`으로 변경 가능)
- 상태마다 이미지 크기가 달라도 하단 중앙에 맞춰 그리므로 발 위치가 고정됨. 그래도 캐릭터 위치가 튀지 않으려면 모든 이미지를 같은 캔버스 크기, 같은 위치로 그리는 것을 권장

`pet.json` (모든 항목 선택):

```json
{
  "name": "곰",
  "size": 128,
  "speed": 80,
  "facing": "right",
  "sleepAfterSec": 600,
  "states": { "click": { "loop": false } },
  "phrases": ["안녕!", "오늘도 수고했어"]
}
```

| 항목 | 의미 | 기본값 |
|---|---|---|
| `size` | 창 크기(px) | 128 |
| `speed` | 걷는 속도(px/초) | 80 |
| `facing` | 원본 이미지가 바라보는 방향 | `right` |
| `sleepAfterSec` | 입력이 없을 때 잠들기까지 걸리는 시간(초) | 600 |
| `states.<상태>.loop` | 반복 재생 여부 | click, dblclick만 `false` |
| `phrases` | 더블클릭하면 말풍선에 보여줄 대사 목록 | 앱 기본 대사 |

기본 캐릭터(곰, 검은 고양이, 푸들, 토끼, 쿼카, 오목눈이)와 각 캐릭터의 대사, 앱·트레이 아이콘은 `npm run make-pets`로 다시 만들 수 있습니다 (`scripts/make-pets.js`).
그림체: 손그림 느낌의 굵은 갈색 외곽선, 납작하고 둥근 떡 같은 몸, 작은 점 눈, 큰 분홍 볼터치, 파스텔 단색.
외곽선을 각도에 따라 조금씩 흔들어 손으로 그린 듯 보이게 하고, 프레임마다 흔들림을 바꿔 선이 살짝 일렁입니다.

| 캐릭터 | 클릭 애니메이션 (무작위) |
|---|---|
| 곰 (`assets/pets/default`) | 점프, 고개 갸웃, 볼 감싸기, 꿀단지 할짝, 하품 |
| 검은 고양이 (`assets/pets/cat`) | 하악질, 그루밍, 사냥 전 엉덩이 씰룩씰룩, 하트, 얼굴만 기울여 부비부비 |
| 푸들 (`assets/pets/dog`) | 점프, 꼬리 흔들기, 고개 갸웃, 발라당 (고개 갸웃은 몸은 그대로 두고 머리만 기울임, 걷기·클릭 때 혀를 내밂, 신날 때 귀가 들썩임) |
| 토끼 (`assets/pets/rabbit`) | 점프, 볼 감싸기, 하트, 당근 뇸뇸, 세수 (볼이 빵빵한 하얀 토끼, 이마와 볼이 움푹 나뉜 얼굴) |
| 쿼카 (`assets/pets/quokka`) | 점프, 고개 갸웃, 볼 감싸기, 하트, 나뭇잎 오물오물 (평소에도 입을 벌리고 활짝 웃는 얼굴, 큰 까만 코, 머리 위에 먹던 나뭇잎, 밝은 볼·턱, 동그란 귀, 가는 꼬리) |
| 오목눈이 (`assets/pets/bird`) | 날갯짓, 날개 펴고 점프, 하트, 고개 갸웃 |

꼬리는 진행 방향의 뒤쪽에 붙습니다. 원본 이미지는 오른쪽으로 가는 기준이라 꼬리를 왼쪽에 그리고, 왼쪽으로 갈 때는 앱이 좌우를 뒤집어 꼬리가 오른쪽에 옵니다. 직접 그린 캐릭터도 같은 기준(오른쪽을 보고, 꼬리는 왼쪽)으로 그리면 됩니다.
