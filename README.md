# Desktop Pet

바탕화면 위에 이미지가 떠 있는 데스크톱 앱 (Electron).
단계별 계획과 검토한 기술 이슈는 [docs/plan.md](docs/plan.md) 참고.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

## 설치

`DesktopPet-Setup-<버전>.exe`를 실행합니다.

- 기본은 "현재 사용자만" 설치라 관리자 권한이 필요 없습니다 (`%LOCALAPPDATA%\Programs\Desktop Pet`)
- 시작 메뉴와 바탕화면에 바로가기가 생기고, 설정 → 앱에서 제거할 수 있습니다
- 제거해도 설정·로그 폴더(`%APPDATA%\desktop-pet`)는 남습니다. 다시 설치하면 그대로 이어서 씁니다
- 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜨면 "추가 정보 → 실행"

## 빌드

```bash
npm install
npm run dist:win      # 설치 프로그램 → dist/installer/DesktopPet-Setup-<버전>.exe
npm run package:win   # 압축 버전(설치 없이 실행) → dist/desktop-pet-win32-x64/
```

`dist:win`은 Windows에서 실행하면 바로 됩니다. Linux·macOS에서는 Wine(32비트 포함)이 필요합니다.
electron-builder가 제거 프로그램을 만들 때 설치 프로그램을 한 번 실행하기 때문입니다.

앱 아이콘(`assets/icon.ico`)은 `npm run make-sample-pet`이 곰을 크기별(16~256px)로 다시 그려서 만듭니다.

## 조작

| 동작 | 방법 |
|---|---|
| 이동 | 이미지를 드래그 |
| 반응 | 이미지를 클릭 (점프) |
| 숨기기/보이기 | `Ctrl + Alt + P`(설정에서 변경 가능), 트레이 아이콘 클릭, 또는 이미지 우클릭 메뉴 |
| 설정 | 이미지 우클릭 → 설정…, 또는 트레이 아이콘 더블클릭 |
| 캐릭터 바꾸기 | 설정 화면, 또는 이미지 우클릭 → 캐릭터 |
| 표시할 모니터 | 설정 화면, 또는 이미지 우클릭 → 표시할 모니터 |
| 전체 화면 앱 중 숨기기 | 설정 화면, 또는 이미지 우클릭 (기본 켜짐) |
| 자동 실행 | 설정 화면, 또는 이미지 우클릭 (빌드한 exe에서만) |

이미지의 투명한 부분은 클릭이 뒤에 있는 창으로 통과합니다. 캐릭터가 그려진 부분만 클릭·드래그됩니다.
| 종료 | 이미지 우클릭 → 종료, 또는 트레이 아이콘 우클릭 → 종료 |

트레이는 작업표시줄 오른쪽 끝(시계 옆) 아이콘 영역입니다. 안 보이면 `^`를 누르세요.

이미 실행 중일 때 exe를 다시 실행하면 새로 뜨지 않고 기존 창을 다시 보여줍니다.

## 캐릭터 동작

| 상태 | 언제 | 재생 |
|---|---|---|
| idle | 기본 | 반복 |
| walk | 2~6초 쉬다가 현재 모니터 안의 근처 지점으로 이동 | 반복 |
| click | 클릭했을 때 | 1회 재생 후 idle. 이미지가 여러 개면 무작위 |
| drag | 드래그하는 동안 | 반복 |
| sleep | 키보드·마우스 입력이 `sleepAfterSec`초 동안 없을 때. 입력이 생기면 깨어남 | 반복 |

## 설정 화면

바꾸면 바로 적용되고 저장됩니다 (저장 버튼 없음). 메뉴에서 바꾼 값도 설정 화면에 바로 반영됩니다.

| 항목 | 내용 |
|---|---|
| 캐릭터 | 기본 제공(곰, 검은 고양이)과 내 폴더 중에서 선택. 재시작 없이 바로 바뀜. **폴더 추가**로 다른 폴더를 등록할 수 있고, 폴더 안 이미지를 바꿨으면 **다시 불러오기** |
| 크기 | 64~256px. 발 위치를 고정한 채 커지고 작아짐 |
| 이동 속도 | 0~200px/초. 0이면 제자리 |
| 잠들기까지 | 캐릭터 기본값 / 안 잠 / 1~60분 |
| 표시할 모니터, 전체 화면 숨기기, 자동 실행 | 메뉴와 같음 |
| 숨기기/보이기 단축키 | 버튼을 누르고 원하는 조합 입력. Ctrl·Alt·Win 중 하나가 있어야 함(F 키는 단독 가능). 다른 프로그램이 쓰는 조합이면 원래 단축키 유지 |

크기·속도·잠들기를 "기본값으로" 되돌리면 캐릭터 `pet.json`의 값을 씁니다.
트레이 아이콘은 지금 캐릭터의 대표 이미지로 바뀝니다.

## 여러 모니터

이미지 우클릭 → **표시할 모니터**에서 고릅니다.

| 선택 | 동작 |
|---|---|
| 자동 (기본값) | 지금 있는 모니터 안에서만 돌아다님. 드래그로 다른 모니터에 옮기면 거기서 돌아다님 |
| 특정 모니터 | 그 모니터 안에서만 돌아다님. 다른 모니터로 드래그해 놓으면 설정이 그 모니터로 바뀜 |

- 설정한 모니터를 빼면 주 모니터로 옮겨 가고, 다시 연결하면 원래 모니터로 돌아옵니다. 메뉴에는 "연결 안 됨 - 주 모니터에 표시 중"으로 나옵니다.
- 모니터는 순서나 ID가 아니라 이름·위치·크기로 기억합니다. 케이블을 다시 꽂거나 도킹을 바꿔 ID가 달라져도 같은 모니터를 찾습니다.
- 해상도·배율이 바뀌거나 작업표시줄 위치가 바뀌면 화면 밖으로 나가지 않게 위치를 다시 맞춥니다.

## 전체 화면 앱

게임, 영상 플레이어, 브라우저 F11처럼 모니터 전체를 덮는 앱이 맨 앞에 오면 캐릭터를 숨깁니다.

- 캐릭터가 있는 모니터만 확인합니다. 다른 모니터에서 영상을 전체 화면으로 봐도 캐릭터는 그대로 있습니다.
- 최대화한 창은 전체 화면으로 보지 않습니다. 창 크기가 모니터와 정확히 같을 때만 전체 화면으로 판단합니다.
- 숨겨진 동안 `Ctrl + Alt + P`로 다시 보이게 하면, 그 전체 화면이 끝날 때까지는 자동으로 숨기지 않습니다.
- Electron에 이 기능이 없어 `koffi`로 Windows API(user32.dll)를 직접 호출합니다 (`src/fullscreen.js`).

## 캐릭터 바꾸기

아래처럼 이미지를 넣은 폴더를 만들고 설정 화면의 **폴더 추가**로 고르면 됩니다.
`%APPDATA%\desktop-pet\pet` 폴더는 따로 추가하지 않아도 목록에 나옵니다. 설정에서 캐릭터를 고른 적이 없으면 이 폴더가 우선입니다.

```
%APPDATA%\desktop-pet\pet\
├── idle.png      필수. 이미지가 없는 상태는 이 이미지로 대체
├── walk.gif
├── click_1.gif   ┐
├── click_2.gif   │ 같은 상태에 여러 개를 두면
├── click_3.webp  │ 그 상태가 될 때마다 하나를 무작위로 재생
├── click_4.gif   │ (직전과 같은 이미지는 연달아 나오지 않음)
├── click_5.gif   ┘
├── sleep.png
├── drag.png
└── pet.json      선택
```

- 파일 이름 = `상태이름.확장자` 또는 `상태이름_아무거나.확장자` (예: `click.gif`, `click_2.gif`, `click_jump.webp`). 확장자는 `.png`, `.apng`, `.gif`, `.webp` 중 아무거나
- 어느 상태든 여러 개 둘 수 있음. 반복 상태(walk, idle 등)는 그 상태에 들어갈 때 하나를 골라 끝날 때까지 유지
- 읽지 못한 파일은 건너뛰고 나머지로 동작
- 정지 이미지와 애니메이션(GIF, APNG, 애니메이션 WebP) 모두 가능. 투명 배경 권장
- 이미지는 오른쪽을 바라보게 그리면 왼쪽으로 걸을 때 자동으로 뒤집힘 (`facing`으로 변경 가능)
- 상태마다 이미지 크기가 달라도 하단 중앙에 맞춰 그리므로 발 위치가 고정됨. 그래도 캐릭터 위치가 튀지 않으려면 모든 이미지를 같은 캔버스 크기, 같은 위치로 그리는 것을 권장

`pet.json` (모든 항목 선택):

```json
{
  "name": "곰",
  "size": 128,
  "speed": 80,
  "facing": "right",
  "sleepAfterSec": 600,
  "states": { "click": { "loop": false } }
}
```

| 항목 | 의미 | 기본값 |
|---|---|---|
| `size` | 창 크기(px) | 128 |
| `speed` | 걷는 속도(px/초) | 80 |
| `facing` | 원본 이미지가 바라보는 방향 | `right` |
| `sleepAfterSec` | 입력이 없을 때 잠들기까지 걸리는 시간(초) | 600 |
| `states.<상태>.loop` | 반복 재생 여부 | click만 `false` |

기본 캐릭터 이미지는 `npm run make-sample-pet`으로 다시 만들 수 있습니다 (`scripts/make-sample-pet.js`).

같은 그림체의 검은 고양이도 기본 제공됩니다 (`assets/pets/cat`, 클릭 이미지 5개: 점프·흔들기·꼬리·갸웃·하트). 다시 만들려면 `npm run make-cat-pet`.

## 구조

```
src/main.js       메인 프로세스: 창, 트레이, 단축키, 상태 전환·이동, 드래그, 모니터, 설정 적용
src/pets.js       캐릭터 폴더 목록·선택·불러오기 (Electron 의존 없음)

src/displays.js   모니터 식별·배치 계산 (Electron 의존 없음)
src/fullscreen.js 전체 화면 앱 감지 (Windows API 호출)
src/preload.js    렌더러에 노출하는 API (window.pet)
src/renderer.js   이미지를 프레임으로 풀어(ImageDecoder) canvas에 재생, 클릭·드래그 감지
src/index.html    canvas
assets/pets/default/  기본 캐릭터 (곰)
assets/pets/cat/      검은 고양이
assets/tray.png   트레이 아이콘
scripts/          캐릭터 이미지 생성 스크립트 (곰, 고양이, 공용 PNG/APNG/GIF 인코더)
test/             모니터 식별·배치, 캐릭터 폴더 테스트 (npm test)
docs/plan.md      단계별 계획
```
